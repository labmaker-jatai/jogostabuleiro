# HAVANNAH

O Havannah é um jogo abstrato de estratégia para dois jogadores, criado pelo matemático e designer de jogos holandês Christian Freeling, por volta de 1976–1980.

O objetivo é construir conexões entre pedras da própria cor para completar uma de três estruturas vencedoras: ponte (Bridge), garfo (Fork) ou anel (Ring).

Diferentemente de jogos como Damas e Xadrez, não existem movimentos de peças ou capturas. A estratégia consiste exclusivamente em escolher os melhores lugares para colocar as pedras.

## 1. Componentes do jogo

Para jogar Havannah são necessários:

- 1 tabuleiro formado por células hexagonais, organizadas em formato de hexágono.
- 2 conjuntos de pedras de cores diferentes.
- 2 jogadores.

Cada jogador utiliza exclusivamente pedras de uma cor.

Dimensões do tabuleiro:

| Versão           | Células por lado | Total de células |
| ---------------- | ---------------- | ---------------- |
| Pequena (base 8) | 8                | 169              |
| Grande (base 10) | 10               | 271              |

O tabuleiro de base 8 é adequado para iniciantes. O de base 10 é bastante utilizado por jogadores experientes.

## 2. Objetivo

O vencedor é o primeiro jogador a construir uma conexão contínua de pedras da sua própria cor que forme pelo menos uma das três estruturas:

1. Ponte (Bridge).
2. Garfo (Fork).
3. Anel (Ring).

Basta completar qualquer uma dessas estruturas para vencer. Não é necessário construir as três.

As pedras utilizadas nas estruturas precisam pertencer ao mesmo jogador e estar conectadas entre si.

## 3. Preparação

1. Coloque o tabuleiro vazio entre os jogadores.
2. Cada jogador escolhe uma cor.
3. Determine quem começa.
4. Disponibilize as pedras de cada jogador.

Na regra tradicional, as pedras brancas começam. Algumas versões utilizam outras cores ou convenções de início.

## 4. Regras de movimentação

O funcionamento dos turnos é bastante simples:

1. Os jogadores alternam suas jogadas.
2. Em cada jogada, o jogador coloca exatamente uma pedra da sua cor em uma célula vazia.
3. A pedra pode ser colocada em qualquer célula vazia do tabuleiro.
4. Não existe obrigação de colocar pedras próximas umas das outras.
5. Uma vez colocada, a pedra permanece naquela posição até o final da partida.
6. Nenhuma pedra pode ser movimentada.
7. Nenhuma pedra pode ser capturada ou removida.
8. Não é permitido colocar uma pedra em uma célula já ocupada, independentemente da cor da pedra existente.

As pedras de cores diferentes não formam conexões entre si. Para construir uma estrutura vencedora, todas as pedras da conexão devem ser da mesma cor.&#x20;

## 5. As três condições de vitória

Esta é a parte mais importante do jogo.

### 5.1. Ponte (Bridge)

A ponte é formada quando um jogador consegue conectar dois dos seis cantos do tabuleiro utilizando uma sequência contínua de pedras da sua cor.

Regras:

- A conexão deve unir dois cantos distintos.
- Os dois cantos podem ser quaisquer dos seis disponíveis.
- As pedras intermediárias devem estar conectadas entre si.
- Não é necessário que os cantos conectados sejam opostos.
- A conexão pode apresentar qualquer formato ou trajetória.

Condição de vitória: conectar dois cantos do tabuleiro com pedras da própria cor.

### 5.2. Garfo (Fork)

O garfo é formado quando um jogador consegue conectar três dos seis lados do tabuleiro utilizando uma sequência contínua de pedras da sua cor.

Regras:

- A conexão deve alcançar três lados distintos.
- Os três lados podem ser quaisquer dos seis existentes.
- As pedras precisam formar uma única conexão contínua.
- Não é necessário conectar lados consecutivos.
- Os cantos do tabuleiro NÃO contam como parte dos lados.

Atenção: esta última regra é muito importante.

Uma pedra colocada exatamente em um canto não pode ser considerada uma pedra pertencente aos dois lados adjacentes para efeito de formação de um garfo.

Condição de vitória: conectar três lados distintos do tabuleiro, sem utilizar os cantos como parte desses lados.&#x20;

### 5.3. Anel (Ring)

O anel é formado quando um jogador constrói uma conexão fechada de pedras da sua cor, cercando pelo menos uma célula do tabuleiro.

Regras:

- As pedras devem formar um caminho fechado.
- O caminho deve retornar ao seu ponto de origem.
- Deve existir pelo menos uma célula completamente cercada pela conexão.
- A célula cercada pode estar vazia.
- A célula cercada pode conter uma pedra do próprio jogador.
- A célula cercada também pode conter uma pedra do adversário.
- O formato do anel não precisa ser circular ou simétrico.

Condição de vitória: construir um circuito fechado de pedras próprias que envolva pelo menos uma célula.

Uma observação importante: não é necessário que o interior do anel esteja vazio. Basta que exista uma região interna delimitada pela conexão.&#x20;

## 6. Regra da troca (Pie Rule ou Swap Rule)

Como o jogador que começa possui uma vantagem estratégica, algumas versões do Havannah adotam a chamada regra da torta (Pie Rule).

Seu funcionamento é:

1. O primeiro jogador coloca uma pedra no tabuleiro.
2. O segundo jogador pode escolher entre duas possibilidades:
   - Fazer sua primeira jogada normalmente.
   - Trocar de posição com o primeiro jogador, assumindo a cor da primeira pedra.
3. Caso escolha a troca, o primeiro jogador passa a utilizar a outra cor.
4. Depois da troca, a partida continua normalmente.

A troca não é uma jogada adicional de colocação de pedra.

Essa regra procura equilibrar a vantagem de quem realiza a primeira jogada.

Importante: a regra da troca é uma regra opcional, não obrigatória em todas as versões do Havannah.&#x20;

## 7. Conexões entre pedras

Para compreender corretamente as condições de vitória, é necessário estabelecer o que significa uma conexão.

No tabuleiro hexagonal, cada célula possui até seis células vizinhas.

Duas pedras são consideradas conectadas quando ocupam células vizinhas e possuem a mesma cor.

Uma sequência de pedras conectadas forma uma cadeia.

Exemplo conceitual:

- Pedra A está conectada à pedra B.
- Pedra B está conectada à pedra C.
- Pedra C está conectada à pedra D.

Consequentemente, A, B, C e D pertencem à mesma cadeia, mesmo que A e D não sejam vizinhas diretamente.

Uma cadeia pode ter ramificações, bifurcações e múltiplos caminhos.

É justamente a construção dessas cadeias que permite formar pontes, garfos e anéis.

## 8. Final da partida e empate

A partida termina imediatamente quando um jogador completa uma das três condições de vitória.

- Ponte: vitória.
- Garfo: vitória.
- Anel: vitória.

Não é necessário esperar o adversário realizar sua próxima jogada.

Se o tabuleiro ficar completamente preenchido sem que nenhum jogador tenha conseguido formar uma estrutura vencedora, a partida termina empatada.

O empate é uma possibilidade teórica, embora não seja o resultado habitual.&#x20;

## 9. Restrições e situações especiais

Para evitar interpretações equivocadas, seguem algumas situações importantes:

| Situação                                | Regra                |
| --------------------------------------- | -------------------- |
| Colocar pedra em célula ocupada         | Proibido             |
| Movimentar pedra já colocada            | Proibido             |
| Capturar pedra adversária               | Proibido             |
| Conectar pedras de cores diferentes     | Não forma uma cadeia |
| Formar ponte entre dois cantos          | Vitória              |
| Formar garfo conectando três lados      | Vitória              |
| Utilizar cantos para completar um garfo | Não permitido        |
| Cercar uma célula vazia                 | Pode formar anel     |
| Cercar uma célula ocupada               | Pode formar anel     |
| Formar mais de uma estrutura vencedora  | Vitória              |
| Preencher o tabuleiro sem vencedor      | Empate               |

## 10. Recomendações estratégicas

Embora o Havannah possua poucas regras, apresenta grande profundidade estratégica.

Algumas recomendações para iniciantes:

- Não concentre todas as pedras em uma única região: procure desenvolver conexões em diferentes partes do tabuleiro.
- Observe os cantos: eles são fundamentais para construir pontes.
- Controle os lados: alcançar três lados diferentes é a condição necessária para construir um garfo.
- Observe os espaços internos: pequenas conexões podem evoluir para anéis.
- Interrompa as ameaças adversárias: procure identificar quando o adversário está próximo de completar uma estrutura vencedora.
- Construa ameaças simultâneas: obrigar o adversário a defender diferentes possibilidades pode proporcionar uma vantagem decisiva.
