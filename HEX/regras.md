# HEX

O HEX é um jogo estratégico de tabuleiro para dois jogadores, baseado na conexão de caminhos. Foi criado pelo matemático dinamarquês Piet Hein, em 1942, e desenvolvido independentemente pelo matemático John Nash, em 1948.

O objetivo é conectar dois lados opostos do tabuleiro utilizando peças da própria cor. O jogo combina simplicidade de regras com grande profundidade estratégica.

## 1. Objetivo do jogo

Cada jogador deve construir um caminho contínuo de peças da sua própria cor, ligando os dois lados opostos do tabuleiro que lhe foram destinados.

- Um jogador utiliza peças de uma cor (por exemplo, vermelha).
- O outro utiliza peças de outra cor (por exemplo, azul).
- Um jogador procura conectar um par de lados opostos.
- O adversário procura conectar o outro par de lados opostos.

Vence quem primeiro conseguir estabelecer uma conexão contínua entre seus dois lados.

Não é necessário preencher todo o caminho em linha reta. As conexões podem apresentar curvas e mudanças de direção.

## 2. Componentes e preparação

- Um tabuleiro formado por células hexagonais.
- Peças de duas cores diferentes, uma para cada jogador.
- Dois participantes.

O tabuleiro tradicional pode ter diferentes dimensões, sendo o formato 11 × 11 um dos mais conhecidos.

Na preparação:

1. Coloque o tabuleiro entre os jogadores.
2. Escolha uma cor para cada participante.
3. Determine quais lados opostos cada jogador deverá conectar.
4. Decida por sorteio quem começa.

Cada célula do tabuleiro deve permanecer vazia no início da partida.

## 3. Regras de movimentação

1. Os jogadores realizam seus movimentos alternadamente.
2. Em cada turno, o jogador coloca uma única peça da sua cor em uma célula vazia.
3. Uma peça colocada não pode ser movimentada posteriormente.
4. Não é permitido colocar uma peça em uma célula já ocupada.
5. Não é permitido retirar, substituir ou mudar a cor de uma peça.
6. Não existem movimentos diagonais ou deslocamentos de peças: a ação permitida é exclusivamente ocupar uma célula vazia.
7. Os jogadores não podem passar voluntariamente a vez.

## 4. Regras de conexão

A conexão entre peças é estabelecida pela vizinhança das células hexagonais.

Duas peças da mesma cor são consideradas conectadas quando ocupam células que compartilham um lado.

Cada célula hexagonal possui seis células vizinhas possíveis.

Para vencer, o jogador precisa formar uma sequência de peças da sua cor em que cada peça seja vizinha de pelo menos uma outra peça da sequência, estabelecendo uma ligação contínua entre seus dois lados de destino.

Não é necessário que todas as peças da sequência estejam em linha reta.

## 5. Regras dos lados e dos cantos

O tabuleiro possui quatro lados, organizados em dois pares de lados opostos.

- Os dois lados de um par pertencem ao primeiro jogador.
- Os outros dois lados opostos pertencem ao segundo jogador.
- As células dos quatro cantos pertencem simultaneamente aos dois pares de lados.

Essa última regra é importante: uma peça colocada em uma célula de canto pode ser considerada conectada ao lado correspondente, independentemente da cor do jogador.

## 6. Condição de vitória

A partida termina imediatamente quando um jogador consegue conectar seus dois lados por meio de uma sequência ininterrupta de peças da própria cor.

Algumas observações:

- A sequência pode ter qualquer formato.
- As peças precisam estar conectadas pelos lados das células hexagonais.
- Não é necessário ocupar todas as células entre os dois lados.
- Não é necessário conectar os lados do adversário.
- A vitória é determinada pela existência de um caminho contínuo, não pela quantidade de peças utilizadas.

## 7. Regra da troca (Pie Rule ou Swap Rule)

Existe uma regra opcional bastante utilizada nas partidas de HEX, chamada Pie Rule ou Swap Rule.

Ela foi criada para compensar a vantagem estratégica de quem realiza o primeiro movimento.

Seu funcionamento é o seguinte:

1. O primeiro jogador realiza sua jogada normalmente, colocando uma peça no tabuleiro.
2. O segundo jogador pode escolher entre duas alternativas:
   - Aceitar a distribuição inicial e realizar sua jogada normalmente.
   - Trocar de cores com o primeiro jogador.
3. Caso escolha a troca, o segundo jogador assume a cor da primeira peça colocada e passa a controlar aquela posição.
4. O primeiro jogador passa a utilizar a outra cor e realiza a próxima jogada.

A troca somente pode acontecer imediatamente após a primeira jogada. Depois que o segundo jogador realiza uma colocação normal, a possibilidade de troca desaparece.

Importante: a regra de troca é opcional. Para partidas introdutórias, pode-se jogar sem ela.

## 8. Empates e encerramento

O HEX possui uma propriedade matemática muito interessante: não existem empates em uma partida convencional.

Isso significa que:

- Sempre haverá um vencedor.
- Não é possível bloquear completamente os dois jogadores simultaneamente.
- Mesmo que todas as células sejam ocupadas, haverá necessariamente uma conexão vencedora.
- A partida termina assim que um dos jogadores estabelece seu caminho.

Essa propriedade é conhecida como Teorema do HEX.

## 9. Estratégias básicas

Embora não sejam regras obrigatórias, algumas estratégias ajudam a compreender o jogo.

Conexão: procure construir caminhos que aproximem suas peças dos dois lados que precisa conectar.

Bloqueio: procure ocupar posições estratégicas que dificultem a conexão do adversário.

Pontes: duas peças podem ficar posicionadas de maneira que existam duas células vazias alternativas entre elas. Essa configuração permite manter uma conexão potencial mesmo que o adversário ocupe uma das células intermediárias.

Controle do centro: as posições centrais geralmente oferecem mais possibilidades de conexão e expansão.

Conexões múltiplas: procure desenvolver mais de uma possibilidade de caminho, evitando depender de uma única sequência de peças.

## 10. Variações permitidas

O HEX admite algumas adaptações sem modificar seu princípio fundamental:

| Variação          | Característica                            |
| ----------------- | ----------------------------------------- |
| Tabuleiro 7 × 7   | Partidas mais rápidas e introdutórias     |
| Tabuleiro 9 × 9   | Partidas de duração intermediária         |
| Tabuleiro 11 × 11 | Dimensão tradicional bastante utilizada   |
| Tabuleiro 13 × 13 | Maior complexidade estratégica            |
| Tabuleiro 19 × 19 | Partidas mais longas e complexas          |
| Com troca         | Utiliza a regra Pie Rule                  |
| Sem troca         | Mantém a ordem convencional dos jogadores |

A dimensão do tabuleiro pode ser alterada, desde que sejam preservadas as regras de conexão entre lados opostos.

## 11. Resumo das regras oficiais para consulta rápida

| Item                 | Regra                                            |
| -------------------- | ------------------------------------------------ |
| Participantes        | 2 jogadores                                      |
| Tabuleiro            | Grade de células hexagonais                      |
| Dimensão tradicional | 11 × 11                                          |
| Peças                | Duas cores diferentes                            |
| Preparação           | Todas as células vazias                          |
| Início               | Sorteio ou acordo entre jogadores                |
| Jogadas              | Uma peça por turno                               |
| Ocupação             | Somente células vazias                           |
| Movimentação         | Não permitida                                    |
| Captura              | Não permitida                                    |
| Retirada de peças    | Não permitida                                    |
| Passar a vez         | Não permitido                                    |
| Conexão              | Compartilhamento de lados entre células vizinhas |
| Objetivo             | Conectar dois lados opostos                      |
| Vitória              | Primeiro a estabelecer a conexão                 |
| Empate               | Impossível                                       |
| Troca de cores       | Opcional, pela Pie Rule                          |

Observação sobre a padronização: o HEX não depende de uma edição comercial específica para suas regras fundamentais. A regra de conexão, a alternância de jogadas e a impossibilidade de empate constituem o núcleo do jogo. A regra de troca é uma convenção adicional bastante difundida.
